## 核心原则速记

1. **真实反馈，不捧杀**：写完必须指出至少 1 个弱点。
2. **平台规则写进每一场**：钩子、卡点、审核、字幕、口型都要可见。
3. **不捏造**：IP、备案号、扶持政策未确认时标【待确认】。
4. **每次输出必附【创作笔记】**。
5. **角色 OOC 检测**：对白符合“性格三层”。

# 第一部分 使用前提

## 1.1 必备前置

硬需（缺则停止）：

```text
项目元信息（项目名、类型、Logline）
人物档案（至少 2 个角色）
剧情主线/大纲
主发平台
备案分类
AI 标识方案
```

软需（缺可继续 + 提示）：

```text
风格调性
世界观
付费卡点
数据目标
```

## 1.2 作品类型判定

| 档案值 | 判定 | 处理 |
|---|---|---|
| 电影/长片/微电影 | 单部 | 一次性完整输出 |
| 短剧（多集）/ 竖屏短剧 / 红果短剧 | 连续 | 先询问写哪一集 |
| 单元剧集 | 连续 | 同上 |

短剧默认：分集开关 = 是。

# 第二部分 写作模式 + 分集开关

## 2.1 M1 标准影视剧本

适合真人短剧、可拍摄交付。

```text
格式：FADE IN / 场景头 / 角色名 / 对白 / CUT TO
动作行：第三人称、现在时、不超过 4 行
一场戏：不超过 1 页（约 250-300 字）
不写心理活动，只写画面
```

## 2.2 M2 小说化叙事剧本

适合 AI 视频生成、漫剧、文学向。

```text
格式：文学化叙述 + 嵌入对白
每段不超过 6 句
心理描写不超过 30%
多用感官词，少用抽象形容词
一场戏 300-800 字
```

## 2.3 分集开关（包装层）

启用后每集必须带：

```text
【集首钩子】0-3 秒抓人
【第一幕 建置】约 25%
【第二幕 对抗】约 50%
【第三幕 解决】约 20%
【集尾钩子】最后 5-10 秒
【付费卡点】如适用
```

# 第三部分 六种节奏（平台增强版）

## 3.1 R1 短剧节奏（最常用）

### 平台时间法则

```text
0:00-0:03   强钩子：视觉刺激 / 矛盾爆发 / 悬念
0:03-0:15   建立人物处境 + 第一次冲突
0:15-0:30   反转 / 信息增量
0:30-1:30   核心矛盾连续推进，每 15-20 秒一个钩子
1:30-2:30   爽点 / 虐点 / 打脸 / 身份揭晓
2:30-3:00   集尾强钩子：悬念 / 误会 / 反转
```

### 平台差异

| 平台 | 写法差异 |
|---|---|
| 抖音 | 前 3 秒要“视觉 + 文字 + 声音”三层钩子；反转密度最高 |
| 快手 | 情绪真实，老铁代入感；避免精英腔 |
| 红果 | 连续爽点，付费卡点前给足情绪；AI 剧日上传有上限 |
| 视频号 | 价值观正向、情感共鸣、转发欲 |
| 小红书 | 女性视角、细腻情绪、真实感 |
| B站 | 可留玩梗空间，弹幕互动 |

### 单集字数与场次

```text
单集 800-1500 字
场景 5-10 个，每场 10-30 秒
对白短促，信息密度高
```

### 付费卡点设计

```text
卡点位置：情绪最高 / 悬念最强 / 大爽点前
每个付费段落自带一次小反转或爽点
男频：每 3-4 集一个付费段
女频：高潮前置，前半段放身份曝光/打脸名场面
禁止：卡点前故意拖戏、虚假预告
```

### 范例（M1+R1+平台版）

```text
场景 1  日.内  董事会议室（0:00-0:05）

   全场寂静。落地窗外阳光刺眼。
   林墨（27）穿着皱巴巴的工装，站在董事会中央。
   字幕：他说我不配坐这个位置。

                   董事长
             （冷笑）
             你也配？

   林墨抬头。

                   林墨
             这家公司，昨天是我的。

   全场死寂。

CUT TO:
```

## 3.2 R3 短视频节奏

适合单条引流、切片、种草。

```text
0-3 秒：三层钩子（视觉/文字/声音）
3-7 秒：悬念/反差
7-30 秒：第一次反转或爆点
30 秒-2 分钟：每 15 秒一个信息点
最后 5 秒：互动钩子 / 下集钩子
```

## 3.3 R2/R4/R5/R6

保留 v1.0 的连续剧、单元剧、微电影、长篇电影节奏，但：

```text
- 目标平台是短视频/短剧时，必须叠加 R1 或 R3 的钩子层
- 慢节奏必须有功能：情绪、悬念、信息、人物关系、视觉记忆
- 严禁无功能留白
```

## 3.4 爆款写作逻辑

### 3.4.1 每场戏必须过“爆款五问”

```text
① 这一场有没有让用户“留下”的东西？
② 这一场有没有让用户“期待”的东西？
③ 这一场有没有让用户“满足”的东西？
④ 这一场有没有让用户“互动”的东西？
⑤ 这一场有没有让用户“分享”的东西？
```

至少命中 2 项；连续 3 场只命中 1 项 = 该段要重写。

### 3.4.2 爆款钩子类型库

```text
身份反差：废物→大佬、普通→隐藏继承人
能力反差：被欺负→碾压反击
关系反差：被嫌弃→被疯狂追求
信息差：只有主角知道真相
威胁升级：反派一次次加码
情感错位：误会、嘴硬、双向暗恋
认知反转：你以为的真相是错的
道德困境：两难选择，逼观众站队
```

### 3.4.3 每集必须预留切片点

```text
切片点 1：0-3 秒强钩子，可独立成一条 15 秒引流视频
切片点 2：中段打脸/反转/名场面，可独立成一条 30 秒切片
切片点 3：集尾悬念，可独立成“下集预告”切片
```

每个切片点必须：

```text
- 有完整小情绪闭环
- 有可截图金句
- 字幕/台词可脱离上下文看懂
- 不剧透关键付费内容（投流切片除外）
```

### 3.4.4 互动与分享设计

```text
评论区：
  选择式提问：你觉得他会原谅吗？
  站队式：你站谁？
  悬念式：猜猜她包里是什么？
  挑战式：你能忍住不看完吗？

分享触发：
  情绪峰值后给一句“共鸣金句”
  给“转发给某人”的暗示（但不能写成导流）
  价值观落点：女性成长、家庭和解、反 PUA
```

### 3.4.5 大结局设计（整剧收尾，防烂尾）

3.12 的"假胜利/尾钩"是单集技巧，整部剧的收尾要靠结构。先按题材选结局类型：

```text
结局类型     情绪回报            适合题材          翻车点
圆满收官    情绪兑现、终成眷属    甜宠/霸总/萌宝     铺垫不足显仓促
留白式      给想象空间、点到为止  悬疑/虐恋/追妻     留太多=没说完=烂尾
开放式      关键选择交给观众      家庭伦理/职场      主线没收干净
反转式      最后一刻推翻认知      悬疑/复仇          为反转而反转
BE/遗憾     用代价强化记忆点      虐恋/年代          只有惨没有主题
```

**反"烂尾"五锁（收尾前逐条过）**：
```text
1. 回收第一集羞辱：终局反打第一屏那次公开压迫，形成闭环。
2. 情感债清算：真相公开≠结束，误判者要"承认/补偿/放权/公开承担"至少一项。
3. 核心秘密兑现：幕后真相、证据、身份在终局审判场集中公开，不再留新悬念。
4. 关系最终选择：主角在"赢"与"保护所爱"之间做一次明确选择。
5. 终局审判场：用一个公开场（董事会/婚礼/直播/家宴/公堂）承载审判，避免私下和解。
```

**终局段结构（长线收口）**：
```text
终局前2-3集：所有人重新站队，幕后操盘者露出。
终局前一集：真相将公开，但公开会伤害主角想保护的人（两难）。
终局集：公开审判场 + 身份/证据/关系/旧账集中兑现 + 第一集羞辱被反打。
结尾：关系最终选择 + 情绪定格，不新增未解之谜。
```

**烂尾预警自检**：
```text
□ 有新角色/新反派在最后5集才空降？   □ 有未回收的第一集强钩子？
□ 情感债只靠"对不起"带过？          □ 真相在最后一集一口气倒完？
□ 用"下一季"掩盖主线没收完？
```
> 结局类型选型的诊断落在 03 的「爆款逻辑体检」，本节负责写作层面的收尾结构。

## 3.5 机制级写作补充

### 3.5.1 正文格式（默认）

```text
短剧正文默认使用：
第几集 / 场次 / 场景 / 人物 / 动作 / 对白

例：
第 3 集
场景 1  日.内  董事会议室
人物：林墨、董事长
动作：全场寂静。林墨穿着皱巴巴的工装站在中央。
对白：
董事长：（冷笑）你也配？
林墨：这家公司，昨天是我的。
```

不要默认写“几秒到几秒”的标签，除非用户明确要求。

### 3.5.2 单场戏最低配置

```text
一个目标：人物当场想得到什么
一个阻碍：谁不让他得到，凭什么
一个信息差：谁知道秘密，谁误判
三次升级：语言、动作、证据、旁观者逐步加压
一次转折：权力、关系或信息发生变化
一个钩子：下一场必须处理的新问题
```

### 3.5.3 竖屏场景语法

```text
人脸：近距离表情变化（误会、忍耐、崩溃、反击）
手部：抢手机、撕合同、递鉴定、按录音
站位：一人被围、两人对峙、旁人站队
小空间：电梯、车内、病房、饭桌、办公室
公开场：婚礼、寿宴、直播、公司大厅
```

每场至少使用两种场景升级动作：逼问、夺物、站队、公开、切断。

### 3.5.4 每集硬规则

```text
每集至少一个不可逆事件
每集结尾必须留下一集问题
前3集：第1集压迫，第2集误判升级，第3集证明类型承诺
第7集：给一次局部回报
第10集：强未完成（将赢未赢、将认未认、将公开未公开）
每10-15集：换目标、敌人、规则、关系或代价
```

### 3.5.5 情绪爆发阶梯

```text
1 忍：不解释，只看对方继续压迫
2 刺：用一句具体旧账反刺
3 揭：拿出证据或指出漏洞
4 断：做出不可逆选择
5 爆：公开判决关系或身份
```

### 3.5.6 对白功能库

```text
逼问句：用具体物件或旧账逼出回答
反击句：不解释清白，只宣布后果
追悔句：说出自己做错的具体动作
挑拨句：把私人问题变成公共判断
钩子句：只说最关键的一半
```

### 3.5.7 类型承诺写作

```text
霸总：必须有权力差 + 公开选择
复仇：必须有旧伤 + 分阶段清算
追妻：必须有具体伤害 + 行动式追悔
神豪：必须有财富反差 + 身份分层释放
战神：必须有隐藏实力分层揭晓
萌宝：孩子必须推动关系、拆谎和站队
```

### 3.5.8 机制级仿写边界

```text
可借鉴：节奏、压力、关系功能、钩子密度、反转位置
必须替换：人物、职业、证据、场景、反转顺序、对白表达
禁止：照搬人物名、完整剧情、连续桥段、台词
```

### 3.5.9 漫剧/3D漫剧适配

如目标为漫剧或 3D 漫剧：

```text
单部短片通常 30-90 秒
场景数 = 总秒数 ÷ 20，下限 2，上限 8
单场景 8-15 秒
剧本需写“空间脚本”：锚点地标 + 站位表 + 机位高度
台词一句约 2-3 秒，停顿写在台词里
```

### 3.5.10 对白情绪标签系统

**核心规则**：每句对白必须标注情绪标签，标签写入对白行前方，格式为 `【情绪】角色名：对白内容`。

```text
常用情绪标签：
  【怒】【惊】【委屈】【狂喜】【崩溃】【心虚】【冷笑】
  【隐忍】【嘲讽】【慌乱】【得意】【失望】【决绝】【感动】

情绪强烈时允许极端卡通表情包变形：
  五官夸张拉伸、眼睛变火焰/星星/漩涡/泪瀑、整张脸切换动态表情包
```

**写作示例**：
```text
【冷笑】林墨：你也配？
【惊】全场死寂。
【隐忍】林墨抬头：这家公司，昨天是我的。
```

**为什么这样做**：
- 情绪标签是下游分镜（05）和提示词（06）的情绪锚点——没有它，AI 只能从上下文猜表情，这是 AI 表情僵硬的源头之一；
- 标签直接对应 04 台词专家的「活人感表演一致性」维度（维度14），让「心里在想事」而非「在做表情」从写作阶段就可执行；
- 短剧节奏要求每 3-5 秒有情绪变化，标签让编剧在写作时就能自查情绪密度。

## 3.6 视觉资产写作协同（v2 增强）

写正文时同步落实三件事，避免剧本与画面脱节：

```text
① 色卡约束写进场景：
   “本场画面配色严格参考 @色卡，统一使用【色彩系统名】，
   人物、建筑、天空、地面、道具都被该色卡约束，
   禁止偏暖/高饱和/鲜艳绿/霓虹色。”

② 身高与站位写进动作：
   “角色A 170cm 站在画面左侧，角色B 185cm 站在右侧，
```

## 3.7 漫剧改编与单集格式（v2 增强）

### 3.7.1 爆款改文强制参数

小说转漫剧短文案时：

```text
开篇 3 秒爆点：第一句必须冲突/绝境/反转/悬念，无铺垫
爽点密度：每 80 字 1 个小爽点，每 200 字 1 个大爽点
段段留钩：每一段结尾留悬念/伏笔/反转预告
对话占比：70% 以上，靠对峙、争吵、博弈、打斗对白推进
景别：全景/中景/近景为主，极少特写
单章：800-1000 字，精炼紧凑
合规：无血腥、暴力、色情、恐怖、低俗、违规描写
```

### 3.7.2 小说转漫剧第一人称润色

```text
人称：全文统一第一人称“我”，不切换第三人称
开头：前 3 句话必须强悬念/钩子
精简：删废话、冗余描写、无关铺垫
画面感：方便转分镜、台词、情绪爆发点

```

### 3.7.3 漫剧单集剧本格式

60 秒单集漫剧剧本默认（v2.7 加「表情具象」「声线」两列，把治僵与配音数据从写作阶段就带进 05）：

```text

字段说明：
【表情具象】只写身体细节，不写"很悲伤/很愤怒"（见 §3.10）。下游 05 直接落进"表情"字段。
【声线】标角色声线（如 极其清冷的女王 / 少年剑客飘逸潇洒），跨集固定，AI 配音不漂移。

例：

...
结尾：设置悬念，引导下一集
```

另附一段完整故事文字，含人物对话，供资产提取与分镜使用。

### 3.7.4 系统角色视觉化规则（实战补充）

**核心规则**：凡是剧情里出现「系统」，默认不用冷冰冰文字面板，改为 Q 版悬浮可爱小人物。

```text
Q版系统小人的视觉DNA：
  圆脸蛋、短小四肢、柔和发光身体、随身携带小型光屏
  默认漂浮在主角身边，高度约主角肩膀位置
  
动作库：
  叉腰、举告示牌、卖萌眨眼、邀功跳舞、委屈发抖、震动变形
  自带喜剧反差效果，玄幻Q版卡通画风

系统信息全部通过小人互动展示（不堆砌文字弹窗）：
  抱光屏、举小黑板、弹出列表、倒计时卷轴、释放礼花特效、弹窗光束
```

**写作时如何写系统小人**：
```text

✅ 正确：Q版系统小人从光屏后探出头，举着小黑板上蹿下跳，

```

### 3.7.5 内心活动视觉化规则（实战补充）

**核心规则**：原文心理活动、设定推理、吐槽内容，不改成旁白，统一改成「角色内心独白」或「Q版内心剧场」。

```text
Q版内心剧场五型（按情绪套用）：

愤怒：角色切成Q版小人 → 背景火山岩浆 → 头顶冒烟 → 文字气泡炸裂
开心：角色切成Q版小人 → 满眼小星星 → 背景撒花+彩色光点 → 原地转圈蹦跳

尴尬：Q版小人僵住流大汗 → 枯叶飘落 → 画面静音留白
崩溃：Q版小人抱头旋转 → 背景碎裂 → 文字气泡乱飞
```

**写作时如何处理心理内容**：
```text
声音/对白栏可写：
  角色内心："……"（短句内心独白）
  Q版内心剧场：角色切成Q版小人+对应背景特效（按五型套用）

禁止：大段画外旁白、长篇设定说明式旁白
允许：画外旁白（仅限开篇世界观简述，不超过2句）
```

## 3.8 连续动作缩写与15秒镜头提示词（v2 增强）

### 3.8.1 缩写规则

```text
像专业小说精简编辑一样压缩章节：
以剧情推进为主线，按原文段落顺序提炼动作、冲突、结果和人物反应；
```

## 3.9 仙侠打斗单集写作补充（实战补充）

写国风仙侠/漫剧打斗单集时，额外落实三件事：

### 3.9.1 口诀式招式台词（大招金句 + 施法节拍）

大招前给角色一句四字/六八字口诀，既是可截图金句，又给施法一个明确起手节拍：

```text
写法：短、四六成句、押韵或对仗；喊出瞬间对应"掐诀/挥袖/亮法宝"的起手动作。
示例：
  "九转铜钱，化为青锋，诛邪破魔，荡尽魍魉！"
  "凤火燎原，焚山煮海。"
  "白玉净瓶，海纳百川！"
  "一剑霜寒十四洲。"
```

### 3.9.2 台词标声线（下游配音不漂移）

每句仙侠台词后标声线：甜美不失英气 / 极其清冷的女王 / 少年剑客飘逸潇洒 /
男青年战士 / 浑厚邪恶的魔族男声。声线跨集固定；不稳的角色注明"建议垫音频"。

### 3.9.3 打斗场"少正脸"写法（配合治表情僵硬）

写打斗动作时，情绪高点默认交给身法与运镜，不写"长时间正脸表情"：

```text
- 高潮/位移：背对镜头、侧脸、回眸、高速运动模糊。
- 正脸只留给：说话镜头（一句一镜）和定格收尾（一个明确表情：淡笑 / 眼神凌厉坚定）。
—— 这样写既顺应 AI 当前能力，也能规避正脸表情僵硬。
```

## 3.10 情绪具象外化表达（实战补充）

**核心问题**：写"她很悲伤 / 他非常愤怒"这类抽象情绪词，AI 只能给一张僵硬的
"标准悲伤脸 / 标准愤怒脸"，眼神空、表情假。从写作阶段就要把情绪拆成
**看得见的身体细节**，下游分镜和出图才有具体动作可依。

### 3.10.1 铁律：情绪不写形容词，写身体动作

```text
禁止（抽象）          →  改写（具象外化）
很悲伤               →  低头，肩膀微微颤抖，指尖攥紧衣角，泪水在眼眶打转却没落下
很愤怒               →  下颌绷紧，喉结上下滚动，青筋暴起，指节因用力而发白
很紧张               →  喉咙发紧咽了口唾沫，视线躲闪，脚在原地蹭了半步
很坚定               →  眉头舒展，眼神从慌乱定住，缓缓抬眼直视对方
很欣喜               →  嘴角先抿住又忍不住上扬，眼尾弯起，呼吸都轻快了半拍
```

**要点**：一处情绪 = 1~2 个可拍的身体细节（眉/眼/唇/下颌/喉结/手/肩/呼吸/身姿），
而不是一个情绪名词。给"未完成的动作"（泪水打转未落、话到嘴边又咽回）比给
"完成的表情"更有张力，也更能规避僵硬。

### 3.10.2 写作落点

- 剧本"动作/表情"栏：只写身体细节，不写情绪名词。
- 情绪高点：交给身法+运镜承载（见 3.9.3），正脸只做一次定格收尾。
- 情绪转折：写"由 A 渐变到 B"的过程细节（如"眼神从悲悯渐变为临危不乱的笃定"），
  给下游一个可运镜的递进，而非一张静态脸。

> 具象外化后的身体细节，会在 05 分镜阶段落进"表情/微表情"字段，
> 并可套用 05 的《情绪表演库》选配运镜——形成从写作到出图的一条治僵闭环。

### 3.11 台词内嵌"演法注释"（实战沉淀）

写对白时，在关键台词后用括号标"怎么演/怎么说"，直接喂给下游 AI 配音（generate_audio），
让声音有起伏、逼近真人，而非播音腔念稿：

```text
"你……终究还是来了。"（气声开头，中途一顿，尾字下沉带一丝哽咽）
"我不信。"（三字逐字加重，末字几乎从牙缝挤出，眼神发狠）
"没关系的。"（表面平静，尾音极轻地抖了一下——强忍）
```
> 只在情绪台词上标，日常口水话不用标，避免堆注释。语气库详见 04 台词专家。

### 3.12 "假胜利"节拍（实战沉淀）

高潮前埋一个"以为赢了→骤然反转"的节拍，是院线级戏剧张力的常用手法：

```text
假胜利结构：主角看似达成目标（松一口气/露出笑意）→ 一个细节露出破绽（对手嘴角上扬/
背景异动）→ 反转打击落下。观众的情绪落差 = 记忆点。
```
> 适合放在每集中段小高潮或大结局前。与钩子配合：反转瞬间正好卡集尾 END FRAME。

## 3.13 情绪曲线节拍表（把"共鸣"变成可量化的一页工具）

§3.5.5 情绪爆发阶梯管的是单场戏内部的情绪升级；本节管的是**整部剧的情绪走向**——用 1-10 分制把每集情绪标出来，让"追更感"变成可自查的硬指标，而不是凭感觉。

**3.13.1 情绪曲线四要素**
```text
- 基线：单剧锁定一个情绪底（约 3.5 分），全剧不长期跌破，跌破观众就划走。
- 高点：爽点/反转/名场面，冲到 6 分以上；分级见下。
- 低点：喘息戏，落到 2-3 分给观众缓冲，但结尾不落回基线以下（要留余味）。
- 转折：1 秒内完成 ≥2 分的情绪跳变（反转的"落差"就是记忆点，接 §3.12 假胜利）。
```

**3.13.2 五条节奏铁律（逐集自查）**
```text
① 单集必有落点：每集结尾留一个情绪余韵（悬念/温情/憋屈），不落回基线 3 分以下。
② 每 3-5 集一个高潮：中高潮 7 分 / 大高潮 8-9 分 / 特大高潮 9 分以上（全剧 ≤3 次，多了钝化）。
③ 全剧走"压→压→爆"三段：以 30 集为例约 7:14:9（压抑铺垫→矛盾累积→集中爆发）。
④ 付费卡点落在大高潮后 1-2 集：卡点前只给到 6-7 分小高潮吊着，别把最大爽点放墙前。
⑤ 结尾必留钩子：主悬念 1 + 次悬念 1（蔡格尼克效应——未完成的事最挂心）。
```
> 用法：分集表出来后，给每集标一个情绪分，连成曲线自查——有没有连续多集低于基线（会掉粉）、高潮是不是扎堆或断档、付费卡点前情绪够不够吊人。这一步接 03 剧本医生的情绪曲线体检。

## 3.14 喜剧节拍章（三翻四抖，补搞笑赛道空白）

短剧的搞笑不是靠台词好笑，是靠**节奏**——铺垫足够的预期，再一下打破。核心是"三翻四抖"。

**3.14.1 三翻四抖结构**
```text
定义：同一套路/情境连续铺垫 2-3 次形成强预期，第 4 次突然掉头打破。
"翻"的数量是虚的（2-6 翻都成立），关键是"翻够"——让观众心里先长出"它接下来会 X"的预判。
三重门铺垫金字塔：
- 一翻（15-30 秒）：一句"抛锚句"立住基础认知（8-15 字，带动作词/方言词更抓人）。
- 二翻：同方向强化核心矛盾（只递进，不换方向，避免观众定位漂移）。
- 三翻：把预期堆到最高（观众此刻最笃定"下一步一定是 X"）。
- 四抖：掉头，给出"意料之外、情理之中"的反预期结果。
```

**3.14.2 抖包袱"一刹那"三铁律**
```text
① 反预期 = 意料之外 + 情理之中（良性违背：荒诞里藏着一条能自圆其说的歪理）。
② 快：笑点释放窗口只有 3 秒，抖完立刻切下一个情绪，不恋战、不重复解释。
③ 狠收尾：最后一个字说完 0.3 秒内用一个动作/硬切切断，不补刀（补刀=尴尬）。
```

**3.14.3 七种反预期方向（单集锁 1 主 + 2 辅，别贪多）**
```text
解构宏大（把庄严的事拉到地面）/ 身份反常规（人设反差）/ 氛围砸挂（气氛烘足突然戳破）/
时空错位 / 信息错位（观众知道角色不知道）/ 语言错位（答非所问、方言反差）/ 动作反转。
```
> 竖屏短剧化提醒：相声小品的铺垫可以慢，竖屏必须快——开场即翻（第一帧已在矛盾里，不铺前史）、4 句话完成一组（每句 ≤15 字）。喜剧节奏落到分镜/提示词见 05/06；金句打磨见 04。
> 合规护栏：不为抖包袱牺牲人设、不靠硬反转硬拗；玩梗不碰地域黑、不踩身材/身份羞辱（题材红线自查见 01）。
